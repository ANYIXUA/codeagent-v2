#001RunAPI规格

上位规格见`../../AGENT.md`

##目标

用户能从CLI提交一次运行，并用返回的`run_id`查询执行结果。CLI通过RunAPI提交和查询任务。

##本阶段范围

本阶段只做API契约，不接真实数据库。调用内存dict模拟数据库。用户在同一个交互式 CLI 会话内提交和查询。固定执行器同步执行，CLI 在本次执行结束后返回 run_id。退出 CLI 后，当前会话的记录失效。

##验收条件

|编号|场景|预期结果|
|---|---|---|
|1|合法输入，执行成功|提交返回 run_id，查询显示「执行成功」和结果
|2|合法输入，执行失败|提交仍返回 run_id，查询显示「执行失败」和原因
|3|非法输入|提交时指出哪里不合法，不创建运行记录
|4|查询未知 run_id|提示「找不到这次运行」

`succeeded`表示本阶段的执行器正常返回。用户交付物是否符合本轮目标，由后续执行Loop阶段验收。
